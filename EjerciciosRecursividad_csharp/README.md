# Ejercicios de Recursividad — C#

Ejercicios de recursividad en C# (.NET), los 3 juntos en `Program.cs`:

1. `Vocales(string)` — cuenta las vocales de una cadena (recursivo).
2. Lee una secuencia de enteros positivos, calcula la suma de dígitos de cada uno de forma recursiva y determina cuál tiene la mayor suma.
3. `S(n) = S(n-1) + n` — suma recursiva de los primeros n números positivos.
